# Deployment

1. Create a public repository named `DanishNadar` under GitHub account `DanishNadar` (or reuse the existing one).
2. Upload README.md and the entire assets/ folder, preserving filenames and structure.
3. Commit to the default branch. GitHub automatically displays the README on your profile.
4. Pin the top six repositories on your profile (suggested: TalonCV, Morph, CampGrids, ConfusionClassifier, ComputeCollaborative, DanishPortfolio).
5. If GitHub's third-party stats service is unavailable, remove the statistics images without affecting the rest of the profile.

This package does not publish changes to your account. It avoids repository links for private work.
